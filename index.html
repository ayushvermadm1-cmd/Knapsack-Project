🎓 Key Concepts (Viva Notes)

What is the Knapsack Problem?

Given items with weights and profits and a knapsack with limited capacity, select items to maximise profit without exceeding capacity.

Greedy Approach (Fractional)

Sort items by profit/weight ratio descending. Pick greedily; take a fraction of the last item if it doesn't fully fit. Always optimal for fractional version.

DP Approach (0/1)

Build a 2D table: dp[i][w] = max profit using first i items with capacity w.
Recurrence: max(dp[i-1][w], profit[i] + dp[i-1][w−wt[i]])

Why Greedy fails for 0/1?

Greedy can leave gaps that no remaining item fills, leading to suboptimal results. DP evaluates all combinations and guarantees the global optimum.

Time Complexities

Greedy: O(n log n) — sorting dominates.
DP: O(n × W) — filling the table.
Greedy is faster when capacity W is very large.

Real-World Applications

Cargo loading, budget allocation, cloud resource scheduling, portfolio optimization, cutting stock, and warehouse inventory management.
